# Linde Wonen

Een fictieve woon- en lifestylewinkel als voorbeeld: verlichting, meubels, woonaccessoires, textiel en servies.

Het is een statische site: `index.html` met de foto's in `wonen/`. Er is geen build-stap nodig. De winkelmand bewaart alles alleen in de browser van de bezoeker en er worden geen echte bestellingen geplaatst.

Foto's via [Unsplash](https://unsplash.com).
